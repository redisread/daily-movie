# 孤鸽镇


> 「《孤鸽镇》之所以今天该看，是因为它告诉你：真正的牛仔不是亡命徒，而是一群在老去之前，最后一次为彼此拼命的老人。」

## 影片简介

前德州巡警奥斯科·麦卡斯林和伍德罗·F·卡拉汉决定联手，驱赶三千头牛，从德州一路跋涉到蒙大拿的荒野牧场。这段跨越三千英里的旅程充满艰险，两位老牛仔在风沙与枪火中，重新思考生命的意义。
